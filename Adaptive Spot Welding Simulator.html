About this model
  • This is a teaching model, not a finite-element weld simulation. Resistance, heat input and nugget growth are simplified so the control idea stays visible.
  • Calibration: the standard schedule holds 9.2 kA and gives a 5.0 mm nugget. The reference weld ran at about 10.2 kA and gives the 6.6 mm simulation result. With the Test 1 settings, Adaptive ON ends near 6.4 mm, the measured value on the slide.
  • The controller applies proportional action to the relative error between measured resistance and the reference curve, with the current limited to 12 kA. Production controllers add integral action, timing and expulsion limits.
  • Each disturbance changes only the heat that reaches the nugget. Real shunts and worn tips also change the measured voltage, which the machine has to interpret.
